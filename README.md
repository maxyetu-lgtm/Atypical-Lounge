Plataforma social acessível e inclusiva, feita em React Native. Onboarding adaptativo, temas dinâmicos, seletor de nível de energia e humor, e acesso a recursos de apoio e crise. Design calmo, sem estímulos agressivos.
# Atypical Lounge

Plataforma social pensada para pessoas que vivem e se comunicam de formas diferentes. O projeto nasceu como um projeto pessoal e acadêmico, com foco em **acessibilidade** e **design inclusivo** desde a base.

## Sobre o projeto

O Atypical Lounge propõe um espaço de convivência mais calmo e respeitoso com o ritmo de cada pessoa. Em vez de impor um fluxo único, o app se adapta ao usuário: o onboarding é adaptativo e a interface muda conforme as preferências de cada um.

## Funcionalidades

- **Onboarding adaptativo**: a jornada inicial se ajusta ao perfil e às necessidades do usuário
- **Temas dinâmicos**: personalização visual do aplicativo
- **Seletor de nível de energia**: o usuário indica como está e a experiência se adapta
- **Seletor de humor**: registro rápido do estado emocional
- **Apoio profissional**: modal com acesso a profissionais de suporte
- **Recursos de crise**: informações de ajuda para momentos difíceis

## Princípios de design

- Paletas calmas e confortáveis para a visão
- Tipografia arredondada e legível
- Nenhum elemento piscante ou estímulo agressivo
- Identidade visual com símbolo do infinito e estética **soft rainbow**

## Tecnologias

- React Native
- Zustand (gerenciamento de estado)
- Protótipo web em HTML com foco em acessibilidade
- Identidade visual em SVG
